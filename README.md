# PowerBI-Retail-Sales-Analysis

## Project Overview

This project was completed as part of the course **Data Visualization: Empowering Business with Effective Insights**.

The objective of this project was to analyze retail sales data and build interactive Power BI dashboards that provide meaningful business insights for decision-makers such as the CEO and CMO.

## Tools & Technologies Used

* Power BI
* Excel
* Data Cleaning
* Data Visualization
* Business Analysis

## Project Tasks Completed

### Data Preparation

* Cleaned raw sales data
* Removed invalid records (negative quantity / incorrect prices)
* Created calculated fields for revenue and time analysis

### Dashboard Insights

1. **Monthly Revenue Trends (2011)**
   Identified seasonal revenue patterns and peak sales months.

2. **Top 10 Countries by Revenue**
   Analyzed highest-performing countries excluding the UK.

3. **Top 10 Customers by Revenue**
   Identified high-value customers for retention strategies.

4. **Demand by Country**
   Compared product demand across international markets.

## Business Value

This dashboard helps leadership teams make better decisions related to:

* Sales forecasting
* Customer retention
* International expansion
* Marketing focus areas
* Demand planning
